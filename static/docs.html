Llearnmate

API reference

Base URL: /api/v1 · JSON responses use a data envelope. Authenticated routes take a bearer access token.

Identity

  • POST /auth/register — create a learner account (teen/adult only in this build)
  • POST /auth/login — exchange email/password for access and refresh tokens
  • POST /auth/refresh — rotate a refresh token
  • POST /auth/logout — revoke the current session
  • GET /auth/me — current account
  • GET, PATCH /learners/me — read or update the current learner profile

Learning

  • GET /courses — age-filtered catalog
  • POST /courses/{course_id}/enroll — enroll in a course
  • GET /courses/{course_id}/lessons — lessons for an enrolled course
  • POST /lessons/{lesson_id}/complete — complete a lesson and earn XP once
  • GET, POST /goals — list or create goals
  • PATCH /goals/{goal_id} — update completion state
  • POST /focus/sessions, PATCH /focus/sessions/{session_id} — record a focus session
  • GET /analytics/overview — weekly activity summary

AI buddy

  • POST /ai/tutor/messages — body: {"message":"…","conversation_id":null}
  • Response includes verification.status. It is verified only when the configured reviewer returns an approval.
